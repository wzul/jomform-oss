## What it catches

**design-system drift** in `web/src/**/*.tsx`: a raw `#rrggbb` literal, a 3-digit hex that carries a letter (`#fff`), or an arbitrary `text-[Npx]` font size. `web/src/app/globals.css` carries a `--jf-*` token layer that WORKS — 1,098 uses across 48 files when this gate was written — and had no governance at all, which is why the UI drifted: measured on the tree it landed on, **153 raw hex literals in 23 `.tsx` files**, three of them different indigos standing in for one brand (`#5e6ad2`, `#7170ff`, `#4f46e5`), and **250 arbitrary px font sizes in six ad-hoc steps** (`text-[11px]` 143×, `text-[10px]` 74×, `text-[13px]` 24×, `text-[12px]` 8×, `text-[9px]` and `text-[15px]` 2× each). `lint` cannot see either: a hex in a Tailwind arbitrary value is legal CSS and `text-[11px]` is a valid utility, so eslint is green on both. The card re-homed every literal on `var(--jf-…)` (11 of the tokens are new: `--jf-accent`, `--jf-primary-strong`, `--jf-text-secondary`, `--jf-text-tertiary`, `--jf-bg-soft`, `--jf-warning-bg`, `--jf-warning-bg-hover`, `--jf-chart-grid`, `--jf-chart-axis`, `--jf-primary-tint`, `--jf-on-color`; the rest already existed) and every size on the named scale `text-jf-{4xs,3xs,2xs,xs,sm,md}` (a Tailwind v4 `@theme` block — a theme entry with no `--text-*--line-height` emits the size alone, which is what a rename needs; Tailwind's own `text-xs` would have silently added its paired 16px line-height). The guard is a SCANNER, so its bite proof is per-run rather than on demand: `scripts/design-guard_test.sh` runs the shipped scanner over 20 sandbox trees and asserts BOTH the exit code and the sentence explaining it — a planted `#ff00ff` and a planted `text-[17px]` are RED naming file:line:value, while the CONTROLS stay green (a hex quoted in a `//` comment and in a `/* */` block, a URL fragment `#affiliate-marketing`, an all-digit `#503`, a hex in `globals.css`, a `.test.tsx` fixture); a broken exemption is its own FAILURE (reasonless → exit 2; unterminated block → exit 2; a stray `-end` → exit 2; a literal AFTER the end marker still bites); a missing or empty `web/src` is exit 2 rather than a vacuous pass; and finally it copies the LIVE `web/src`, proves it green, plants one hex in the real `builder/page.tsx` and proves that same copy red naming the value, then restores the copy and proves it green again — so the red is attributable to the plant, not to the tree. 35 checks, ~7s, offline (python3 only, no network, no browser, no database). The escape hatch is per-line and justified (`design-tokens-exempt: <reason>`, 8+ chars minimum, or a `…-end`-closed block for a JSX child that cannot hold a comment); it is used 9 times on the tree this gate landed on — the brand page, whose hex strings ARE the rendered content, two colour-picker defaults that are persisted data (`#7c3aed`, `#ffffff`, `#5e6ad2`), and one usage sentence that names the brand colour — and every honoured exemption is printed on the pass line so the list is auditable rather than invisible. Card `t_d5336ec6` extended the same scanner to MOTION, because a raw `duration-<n>ms` is the animation's version of a raw hex: a `transition-all` (it transitions EVERY property, layout ones included, so a resize becomes a per-frame layout), a `duration-<n>ms` / `duration-[<n>ms]` at a call site (the app's three steps are the tokens `--jf-dur-fast|base|slow`), and a `web/src/app/globals.css` with no `@media (prefers-reduced-motion: reduce)` block that collapses BOTH `animation-duration` and `transition-duration` are each a FAILURE — the last is not a `.tsx` rule, it is checked because motion that ignores the OS accessibility setting is the exact defect that card exists to fix, and a card that ships an animation without that block must not be able to pass here. Each rule has a planted control, each is also proven red on a copy of the REAL `web/src` (a planted `transition-all`, a planted `duration-250ms`, and the real stylesheet with its baseline switched to `no-preference`), and the duration rule's CONTROL is the token form `duration-[var(--jf-dur-base)]`, which must stay green
