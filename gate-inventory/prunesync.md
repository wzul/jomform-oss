## What it catches

the copy the cron job **RUNS** must be the revision the branch **MERGED** (card `t_d9cf1ddd`). The job resolves `script: prune-kanban-worktrees.sh` under `$HERMES_HOME/scripts` — outside the checkout — and the only thing that ever updated that copy was the **manual** installer, so every merge touching `deploy/worktrees/*` left the running pruner stale until a lane remembered: measured three times, each hash-verified — `e3137b91` running until 2026-10-08 **without the `has_process_matching` live-process guard** while the nightly job kept executing it (fixed by hand during `t_a7312c6c`), the suite `620fbd5b` on 2026-10-10 two days after a card had declared the install satisfied (`t_82b6ae3c`), and `05474f06`/`97ff705a` on 2026-10-15, missing #1158's reaped-pid skip and #1161's artefact count (11 non-comment lines — measured while writing this gate). The harness proves the checker **BITES**: its 2026-10-08 fixture *is* those bytes, pinned by sha256, and the checker must call that pair drift **naming the missing guard**, while the **same** bytes against their **own** revision read green (the control that keeps the red attributable); an **EMPTY** host copy, a job that is **armed while its script is gone**, a reference that does not resolve and a ref that carries no such file are each RED; a machine with no pruner and no job pointing at one is green **only** as a NOTE reporting the `0 pair(s)` it compared — never a byte-identical verdict it did not make; the drifted run leaves both host files byte-identical (it never writes — a check that "fixed" the host inside a lane's run would install unmerged bytes on a destructive nightly job); the compared set is READ from the installer's `--print-targets` (sabotage arm, so a file the installer starts installing cannot become one nobody compares); the repair the verdict names (`--from-ref <rev>`) installs the **REF's** bytes and not the working tree's, refuses an unresolvable/partial/empty ref, and its full proof path exits 0; and three of the checker's **own** branches (the byte comparison, the empty-file refusal, the no-pruner branch) are neutered on a copy — with the edit's anchor counted, so a sed that did not land is REFUSED — and required to flip their own arm.
